# Если интерфейс выглядит «сломанным» после обновления

Симптомы: лента чата обрывается на середине, поле ввода висит посреди экрана,
сообщения вылезают ниже композера, сайдбар пустой.

Причина: браузер отдаёт **старый** `style.css` из кеша, в котором ещё нет
правил фиксированной высоты для `.chat-area > .view-pane` / `#home-chat`.
Начиная с v12 это невозможно, но если ты сидишь на старой вкладке:

1. `Ctrl+Shift+R` (Windows/Linux) или `Cmd+Shift+R` (macOS) — жёсткая перезагрузка;
2. DevTools → Application → Service Workers → **Unregister**, затем перезагрузить;
3. DevTools → Network → включить «Disable cache» и перезагрузить.

Проверить, что пришла свежая версия, можно по адресу в `<head>`:
в исходнике страницы ссылка должна выглядеть как
`/static/style.css?v=<12 символов хеша>` (раньше было `?v=10`).
