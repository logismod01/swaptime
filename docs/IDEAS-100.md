# 100 идей: что можно добавить на страницы СвапТайма

Собрано под текущий интерфейс: экран входа, рейл серверов, сайдбар чатов, друзья,
личный чат, каналы сервера (Discord), каналы-ленты (Telegram), карточка профиля,
настройки, звонки, мобильная версия/PWA.

Метки сложности: 🟢 быстро (до дня) · 🟡 средне (1–3 дня) · 🔴 крупно (неделя и больше).

## Экран входа и регистрации (1–5)

**1. Вход по QR-коду** · 🔴 крупно  
На телефоне уже открыт аккаунт — сканируешь QR и входишь на десктопе, как в Telegram Web и WhatsApp Web.

**2. Управление сессиями и устройствами** · 🟡 средне  
Список активных входов с датой, IP и кнопкой «завершить» — прямо в настройках и на экране входа.

**3. Гостевой демо-режим** · 🟡 средне  
Кнопка «Посмотреть без регистрации»: одноразовый аккаунт с демо-чатом, чтобы человек сразу понял, как всё работает.

**4. Индикатор силы пароля** · 🟢 быстро  
Полоска под полем: длина, цифры, регистр, «такой пароль уже в базе утечек» — и мягкие подсказки.

**5. Капча-эмодзи вместо суммы** · 🟢 быстро  
Вместо «сколько будет 3 + 5» — выбрать нужные эмодзи из сетки (веселее и понятнее с телефона).


## Рейл (левая панель) (6–12)

**6. Перетаскивание серверов** · 🟡 средне  
Сортировка серверов мышью/пальцем с сохранением порядка в профиле — как в Discord.

**7. Папки серверов** · 🔴 крупно  
Объединять серверы в папки с названием и цветом, сворачивать/разворачивать.

**8. Мини-профиль по клику на свою аватарку** · 🟢 быстро  
Быстрая карточка: статус, ник, кнопка «настройки» и «сменить статус» без открытия модалки.

**9. Счётчик друзей онлайн** · 🟢 быстро  
Бейдж у иконки «Друзья»: «3 из 12 в сети» — видно, есть ли смысл заходить.

**10. Быстрый переключатель статуса** · 🟡 средне  
Долгое нажатие на свою аватарку → колесо статусов (в сети / отошёл / не беспокоить / невидимка).

**11. Шаблоны серверов** · 🟡 средне  
«Создать сервер» → шаблоны: игровой (каналы #общий #поиск-игры #мемы), учёбный, для друзей.

**12. Бейдж «что нового»** · 🟢 быстро  
Точка на иконке настроек со списком изменений последней версии — чтобы правки не проходили незаметно.


## Сайдбар: личные сообщения (13–22)

**13. Группировка по времени** · 🟢 быстро  
Разделы «Сегодня», «Вчера», «На этой неделе», «Старые» — как в мессенджерах на телефоне.

**14. Папки и категории чатов** · 🟡 средне  
Свои папки («Работа», «Друзья», «Игры»), перетаскивание чатов между ними.

**15. Счётчики по папкам** · 🟢 быстро  
Красный бейдж на папке с суммой непрочитанных.

**16. Сортировка списка** · 🟢 быстро  
Переключатель: по времени / по алфавиту / сначала непрочитанные.

**17. Контекстное меню чата** · 🟢 быстро  
Правый клик: закрепить, тишина, архив, прочитано, удалить историю.

**18. Архив чатов** · 🟡 средне  
Свернуть ненужные диалоги в архив с отдельным входом и поиском.

**19. Статус-точка на аватарке** · 🟢 быстро  
Зелёная/жёлтая/красная точка прямо на аватарке в списке — видно статус без открытия чата.

**20. Свайпы на телефоне** · 🟡 средне  
Свайп по чату влево: «прочитано», «тишина», «в архив» — с анимацией.

**21. Глобальный поиск по всем чатам** · 🔴 крупно  
Полнотекстовый поиск (SQLite FTS5) с результатами-сниппетами и переходом к сообщению.

**22. Кнопка «Новый диалог»** · 🟢 быстро  
Быстрый старт переписки по нику прямо из сайдбара, без похода во вкладку «Друзья».


## Друзья (23–29)

**23. Группировка по статусу** · 🟢 быстро  
Заголовки «В сети (3)», «Отошёл (1)», «Не в сети (8)».

**24. Поиск с подсветкой совпадений** · 🟢 быстро  
Подсвечивать буквы совпадения в нике и имени.

**25. Вид «плитка»** · 🟡 средне  
Переключатель список/сетка аватарок — удобно, когда друзей много.

**26. Быстрые действия на карточке** · 🟢 быстро  
Иконки «написать» и «позвонить» прямо в строке друга при наведении.

**27. Приватные заметки о друге** · 🟡 средне  
«Познакомились на конференции» — видно только тебе.

**28. Экспорт и импорт друзей** · 🟡 средне  
Скачать список ников или загрузить файл и разослать заявки разом.

**29. Реферальная ссылка** · 🟡 средне  
Приглашение по ссылке /r/<ник>: новый человек регистрируется — вы сразу друзья.


## Чат (личные сообщения) (30–45)

**30. Ответ двойным кликом** · 🟢 быстро  
Двойной клик (или свайп) по сообщению — сразу цитата, как в Telegram и Discord.

**31. Голосовые сообщения** · 🔴 крупно  
Кнопка-микрофон, запись по удержанию, волна, скорость 1×/1.5×/2×.

**32. Кружочки (video note)** · 🔴 крупно  
Короткое видео с камеры в круглом пузыре.

**33. Файлы и картинки** · 🔴 крупно  
Прикрепление до 25 МБ, превью изображений, скачивание по клику.

**34. Галерея изображений** · 🟡 средне  
Несколько фото в сетке с полноэкранным просмотром и стрелками.

**35. Стикеры и GIF** · 🔴 крупно  
Набор стикеров + поиск GIF (Tenor/Giphy API) в панели композера.

**36. Эмодзи-пикер в композере** · 🟢 быстро  
Сетка эмодзи с поиском по названию и недавними.

**37. Упоминания @ник** · 🟡 средне  
Автодополнение при вводе @, подсветка упоминания и бейдж «тебя упомянули».

**38. Опросы** · 🔴 крупно  
Создать опрос с 2–10 вариантами, голоса в реальном времени, видно кто как проголосовал.

**39. Навигация по закреплённым ↑↓** · 🟢 быстро  
В панели пинов стрелки «предыдущий/следующий» без закрытия панели.

**40. Переход к дате** · 🟡 средне  
Мини-календарь в шапке: выбрать дату и прыгнуть в историю.

**41. Разделители по датам** · 🟢 быстро  
«Сегодня», «Вчера», «12 октября» между блоками сообщений.

**42. Кто прочитал** · 🟡 средне  
В личном чате показывать «прочитано» с галочками, как в WhatsApp.

**43. Исчезающие сообщения** · 🔴 крупно  
Таймер на чат: сообщения удаляются через 1 час / 1 день / 7 дней.

**44. Правка в пузыре** · 🟡 средне  
Редактировать текст прямо в сообщении, без отдельной панели сверху.

**45. Быстрые ответы** · 🟢 быстро  
Свои заготовки фраз («оки», «буду через 10 минут») по слэшу в поле ввода.


## Серверы и каналы (Discord) (46–55)

**46. Категории каналов** · 🟡 средне  
Сворачиваемые группы каналов с названием.

**47. Приватные каналы** · 🔴 крупно  
Канал виден только выбранным ролям, остальные его не видят в списке.

**48. Голосовые каналы с составом** · 🔴 крупно  
Под каналом список тех, кто сейчас в голосовом, с иконкой микрофона.

**49. Треды** · 🔴 крупно  
Ветка обсуждения под сообщением со своим списком и счётчиком ответов.

**50. Медленный режим** · 🟢 быстро  
Slowmode: один участник может писать раз в N секунд.

**51. Форум-каналы** · 🔴 крупно  
Канал-список тем: каждая тема — отдельное обсуждение, как в Discord Forum.

**52. Фильтр участников** · 🟢 быстро  
Поиск по нику и вкладки «Владельцы / Админы / Участники / В сети».

**53. Кастомные роли** · 🔴 крупно  
Свои роли с цветом, названием и набором прав (писать, закреплять, кикать).

**54. Приглашения с лимитами** · 🟡 средне  
Ссылка-приглашение с ограничением по срокам и количеству входов, список активных инвайтов.

**55. Настройки канала** · 🟡 средне  
Тема, иконка-эмодзи, права на запись, скрытие из списка.


## Telegram-каналы (56–65)

**56. Реакции на посты** · 🟢 быстро  
Те же эмодзи-реакции, но под постами канала с счётчиком.

**57. Комментарии к постам** · 🔴 крупно  
Обсуждение под постом — мини-тред с лайками.

**58. Отложенные посты** · 🔴 крупно  
Написать сейчас — опубликовать в назначенное время, с черновиками.

**59. Мульти-фото в посте** · 🔴 крупно  
До 10 изображений в посте, свайп-галерея и превью в ленте.

**60. Опросы в каналах** · 🔴 крупно  
Анонимные и открытые опросы с результатами в процентах.

**61. Счётчик просмотров** · 🟡 средне  
Сколько людей увидели пост (по уникальным читателям).

**62. Закреплённый пост** · 🟡 средне  
Один закреплённый пост сверху ленты канала.

**63. Поделиться постом** · 🟢 быстро  
Ссылка на конкретный пост + красивая карточка-превью (Open Graph).

**64. RSS-автопостинг** · 🔴 крупно  
Подключить RSS-фид — новые записи автоматически публикуются в канал.

**65. Статистика канала** · 🔴 крупно  
Графики подписчиков, просмотров и реакций за неделю/месяц.


## Профиль и карточка (66–73)

**66. Смена ника** · 🟡 средне  
Раз в 30 дней, со проверкой занятости и сохранением старого ника в резерве.

**67. QR-код профиля** · 🟢 быстро  
Код, по которому другой человек сразу открывает карточку и может добавить в друзья.

**68. Музыкальный статус** · 🟡 средне  
Строчка «слушает …» рядом со статусом, включается вручную.

**69. Ссылка на профиль** · 🟢 быстро  
Красивый адрес `/u/<ник>` и кнопка «скопировать ссылку».

**70. Анимированная аватарка** · 🟡 средне  
GIF/WebP-аватар в карточке профиля.

**71. Достижения и бейджи** · 🔴 крупно  
«Первый сервер», «100 сообщений», «Ночной житель» — видно в профиле.

**72. Кастомизация карточки** · 🟡 средне  
Свой фон, шрифт и рамка карточки профиля, не только баннер.

**73. Профиль картинкой** · 🟡 средне  
Кнопка «поделиться профилем» — генерирует PNG-карточку для соцсетей.


## Настройки (74–83)

**74. Свой акцентный цвет** · 🟡 средне  
Помимо 10 тем — выбор любого акцента и фона из палитры.

**75. Прозрачность и блюр** · 🟡 средне  
Регулировка прозрачности панелей и силы размытия фона.

**76. Устройства и сессии** · 🟡 средне  
Список входов, «выйти везде», автозавершение старых сессий.

**77. Экран горячих клавиш** · 🟡 средне  
Все шорткаты в одном месте + возможность переназначить.

**78. Языки интерфейса** · 🔴 крупно  
RU / EN с переключателем и словарём строк.

**79. Плотность интерфейса** · 🟢 быстро  
Компактный / обычный / просторный режим сообщений.

**80. Экспорт своих данных** · 🟡 средне  
Скачать JSON со своими сообщениями, профилем и настройками.

**81. Удаление аккаунта** · 🟡 средне  
С двухшаговым подтверждением и сроком «отменить в течение 7 дней».

**82. Выбор звука уведомлений** · 🟢 быстро  
Несколько сигналов с предпрослушиванием и ползунком громкости.

**83. Гибкая приватность** · 🟡 средне  
Кто может писать, звонить, приглашать на сервер, видеть статус.


## Звонки (84–91)

**84. Групповые звонки** · 🔴 крупно  
3+ участников: сетка видео, «поднять руку», список участников.

**85. Демонстрация окна** · 🟢 быстро  
Выбор источника: весь экран / окно / вкладка, плюс курсор и системный звук.

**86. Размытие фона** · 🔴 крупно  
Виртуальный фон и блюр камеры средствами браузера (MediaPipe/Segmentation).

**87. Запись звонка** · 🟡 средне  
Запись в файл WebM с индикатором и сохранением на устройство.

**88. Тест устройств** · 🟡 средне  
Экран перед звонком: слышно ли микрофон, видно ли камеру, выбор устройств.

**89. Переключение камеры** · 🟢 быстро  
На телефоне — фронтальная/задняя кнопкой в звонке.

**90. Заглушка при выключенной камере** · 🟢 быстро  
Аватарка с инициалами вместо чёрного экрана.

**91. Мини-режим звонка** · 🟡 средне  
Picture-in-Picture: звонок свёрнут в окошко поверх других окон.


## Мобильная версия и PWA (92–96)

**92. Нижний таб-бар** · 🟡 средне  
Чаты / Друзья / Каналы / Серверы / Я — вместо скрытого рейла на телефоне.

**93. Свайп «назад»** · 🟢 быстро  
Свайп от левого края возвращает из чата к списку.

**94. Push-уведомления** · 🔴 крупно  
Web Push + VAPID: уведомления приходят, когда приложение закрыто.

**95. Ярлыки приложения** · 🟢 быстро  
Долгое нажатие на иконку → «Новый чат», «Избранное», «Избранные» (manifest shortcuts).

**96. Офлайн-очередь** · 🟡 средне  
Написал без сети — сообщение отправится само, когда связь вернётся (с индикатором).


## Сквозные «вкусности» (97–100)

**97. Светлая тема** · 🟡 средне  
Настоящая светлая палитра в дополнение к 10 тёмным градиентам.

**98. Глобальный поиск** · 🔴 крупно  
Ctrl+Shift+F: люди, сообщения, каналы, серверы — всё в одном окне.

**99. Командная палитра** · 🟡 средне  
Ctrl+/ — список всех действий («создать канал», «включить тишину»).

**100. Онбординг-тур** · 🟢 быстро  
Подсказки при первом входе: где серверы, реакции, быстрый переход.


## Что бы я сделал первым (топ-12)

| # | Идея | Почему именно она |
|---|------|-------------------|
| 1 | Вход по QR-коду | самый заметный «вау» на первом экране, сразу видно, что продукт современный |
| 31 | Голосовые сообщения | самая частая просьба в мессенджерах после текста |
| 34 | Файлы и картинки | без них чат «недоделан» — люди шлют скриншоты постоянно |
| 46 | Категории каналов | серверы с 5+ каналами уже неудобно листать |
| 56 | Реакции на посты каналов | реакции в личке уже есть — это дёшево и красиво |
| 97 | Светлая тема | часть людей просто не пользуется тёмными интерфейсами |
| 92 | Нижний таб-бар на телефоне | мобильный сценарий — основной для мессенджера |
| 94 | Push-уведомления | без них с телефона не вернутся |
| 39 | Навигация по закреплённым | уже есть пины — не хватает стрелок |
| 21 | Поиск по всем чатам | переписка растёт, найти старое сообщение сейчас нельзя |
| 84 | Групповые звонки | звонки уже работают 1-на-1, групповые — логичный шаг |
| 100 | Онбординг-тур | фич стало много, новичок теряется |

## Как это связано с кодом

| Страница | Файлы |
|----------|-------|
| Экран входа и регистрации | `frontend/index.html` (форма), `frontend/script.js` (капча, вход), `backend/server.py` (`/api/register`, `/api/login`) |
| Рейл | `index.html` (`.rail`), `script.js` (`renderRail`, `renderServerRail`), `servers.js` |
| Сайдбар чатов | `script.js` (`renderDMList`, `renderSidebar`), `features.js` (`decorateChatList`) |
| Чат | `script.js` (`buildMessageNode`, `sendMessage`), `features.js` (поиск, реакции, форматирование) |
| Серверы и каналы | `servers.js`, `style.css` (`.channel-item`, `.members-panel`) |
| Telegram-каналы | `channels.js` (лента, посты, подписки) |
| Профиль | `script.js` (`openProfile`), `style.css` (`.profile-card`, баннеры, рамки) |
| Настройки | `script.js` (`openSettings`, `saveSettings`), `calls.js` (качество звонков) |
| Звонки | `calls.js` (WebRTC, экран, статистика), `/api/ice` |
| Мобильная версия/PWA | `style.css` (`@media`), `sw.js`, `pwa.js`, `manifest.webmanifest` |
